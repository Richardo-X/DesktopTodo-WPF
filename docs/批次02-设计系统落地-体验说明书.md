## 一、这一批做了什么（一句话）

把上一版已经验收过的"样子"在 WPF 里建成一套统一规格库，并给你一个静态主窗预览＋规格陈列切换＋磨砂实验窗；功能（新建待办等）本批不做。

## 二、你会看到什么

双击 **`preview\TodoWpf.exe`**（仓库根目录 F:\AI\VBcode\project\todo-wpf 下）会出现两个无边框卡片窗：

1. **外观预览 · 待办主窗（静态）**：长得跟成品主窗一样——标题栏（品牌勾＋桌面待办＋月亮/图钉/缩进锁/齿轮/×五枚图标按钮）、居中时钟＋日期、操作区（⚡ / 3/10 / 批量删除 / ☑ / ＋）、四条假待办（一条带逾期红标、一条长文本截断）。**全是假数据**：能悬停（行变色）、能按住按钮看按压缩小反馈，但点了不会发生业务。
2. **磨砂实验窗**：一张半透明卡面＋"磨砂：开/关"按钮。

可用的三个预览工具功能（窗口内有标注，非产品功能）：
- 标题栏**月亮按钮**＝切换日/夜主题（整窗实时换色）；
- 右下角**「规格检查」**＝切换到零件陈列（文字三阶/关键色/圆角阶梯/按钮阶梯/17 枚图标集/确认框样张/动效说明，全部标注规格值），再点「返回外观」切回；
- 磨砂窗的**「磨砂：开/关」**＝切换 DWM 真磨砂。

## 三、怎么操作验证（真机步骤）

1. 双击 `preview\TodoWpf.exe`（两个窗口同时出现）。
2. **对照原型**：浏览器打开 `docs\参考\交互原型-v3.4-taste.html`，并排比对主窗观感（两套主题都切一遍：点月亮按钮）。
3. **看零件**：点「规格检查」，逐组核对规格值标注；点「返回外观」回来。
4. **磨砂判定（C2）**：把磨砂窗拖到壁纸上（按住标题栏拖）→ 磨砂"开"：文字背后壁纸应被**模糊**；"关"：半透明但背景清晰。观察有没有黑块/拖影/卡顿。
5. **按压反馈**：按住任一按钮（如批量删除）→ 轻微缩小（scale 0.96），松开复原。
6. 关闭两个窗口即退出预览（不留任何后台、不写任何数据文件）。

## 四、什么算通过

- 两套主题下，主窗观感与原型 v3.4 一致（配色三阶、6px 圆角、32/30/26/28/20 按钮阶梯、线性图标、时钟等宽数字）；
- 规格检查陈列与标注值一致；磨砂窗能明确得出"本机真磨砂可用/不可用"的结论（结论由你观察后反馈）；
- 按压反馈顺滑；无乱码、无错位、无闪烁。

## 七、技术要点与已知差异（如实记录）

- **令牌体系**：颜色/半透明画刷=DynamicResource（日夜切换实时生效）；尺寸/圆角/时长/缓动=StaticResource（运行期不变）。测试锁定全部令牌值，改值必须显式改测试。
- **图标**：17 枚几何全部来自原型 I.* SVG 逐值转换（WPF Path 微语言兼容 SVG d），单族线宽 1.7/1.8/2（勾 3/品牌勾 3.4），测试锁定。
- **动效**：按压反馈=真动画（SplineDoubleKeyFrame，cubic-bezier(.22,.61,.36,1)，120ms）；悬停变色=瞬时（WPF 悬停颜色过渡需逐状态画刷克隆，随批次 03 一并做）；**减少动画关怀**=系统关闭客户端动画时（WPF SystemParameters.ClientAreaAnimation）启动自动合并零时长覆盖。
- **磨砂（C2）**：SetWindowCompositionAttribute ACCENT_ENABLE_ACRYLICBLURBEHIND（Win10 1803+/Win11 通用通道），底色=白天卡面色调 α60%；拖动流畅度属真机观察项。
- **已知差异 1**：非 BMP 字符不涉及；本批无。
- **已知差异 2**：CSS 逐元素 backdrop-filter 无 WPF 对应物，本套未使用（磨砂只做窗口级，符合 C2 判定）。
- **过程记录**：Debug bin 曾存在批次 01 模板壳旧 exe 导致冒烟假阳性；已改用 Release publish（`preview\`）作为验收产物，杜绝旧产物干扰。cmd `start` 启动链在本开发机被安全软件拦截（"拒绝访问"），交付物改为"直接双击 exe"绕开启动链；未做任何杀软配置改动。
