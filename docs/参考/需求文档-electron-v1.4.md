## 一、产品概述

Windows 桌面待办组件：悬浮小窗、免登录、不联网、数据只存本地、重启不丢。不占任务栏，托盘图标控制显隐，右键托盘"退出"是唯一关闭途径。适配 Win10/Win11，界面简体中文。

## 二、整体布局与窗口行为

**组件与桌面的关系**：组件整体没有统一底板，各面板为独立悬浮卡片；面板之间的空隙与窗口圆角外区域完全透明，直接显示用户桌面（v1.1：点击穿透已按用户决定移除，缝隙不响应桌面操作）。面板自身为半透明磨砂背景（白天/夜晚两套配色，样式基准见原型 v3），隐约透出桌面壁纸。

**组件簇布局**：快捷添加面板（左）＋ 待办主窗口（中）＋ 已完成面板（右）并排成组；左右面板可各自打开/隐藏，开关状态记忆，下次启动恢复；拖任一面板标题栏移动整个组件簇，位置自动记住。

**工具栏（主窗标题栏，v1.4 顺序修正）**：日/夜主题切换、窗口置顶开关、缩进锁定、设置、×（缩小到通知栏）——与应用 v1.1.0 实现及验收一致（原记录顺序为笔误）。

**缩放**：拖主窗右下角缩放柄，三个面板**等比例**一起缩放；子窗口右下角也有缩放柄，按类别分组（事项类/模板类/设置/历史）等比缩放。
- **上限**：所有窗口（常驻三面板簇**和子窗口**）高度均不超过**屏幕高度的一半**，宽度均不超过屏幕宽度
- **下限**：窗口内时钟、按钮、事项行等所有元素完整可见、正常排布，不挤压、不裁切、不隐藏任何组件
- **缩进状态下的缩放流程**：组件缩进时只露小条，缩放柄不可见、无法点击；鼠标划到小条组件**弹出后**才能抓缩放柄缩放；缩放期间（按住不放）组件保持弹出，直到松开鼠标；松开后鼠标仍在组件上时保持弹出，移开约半秒自动缩回

**子窗口**：新建/编辑/设置/历史等子窗口可单独拖动（限制在屏幕内）、位置不记忆（每次打开回默认位置）、打开时置顶并**锁定其他窗口**（模态），且组件自动弹出缩进状态。

**贴边缩进（仅上边缘）**：组件拖近屏幕上边缘自动吸附贴齐；默认状态：鼠标离开约半秒后自动缩进只留小条（约 12 像素），鼠标划过弹出；**缩进锁定**开启后贴边但保持弹出不缩进；有子窗口打开时始终弹出。缩进 ≠ 最小化：缩进只是贴边收纳，托盘双击控制的是整体显示/隐藏，两者独立。

**托盘与运行**：× 或双击托盘图标＝缩小到通知栏/恢复（带动画）；托盘右键菜单＝「显示/隐藏」「退出」（退出弹确认框，唯一关闭途径；若当时有编辑窗口存在未保存输入，确认框中一并提示）；单实例运行，已开启时双击 exe 只调出现有窗口。置顶状态记忆。

**其他**：屏幕分辨率变化或拔掉显示器时，组件自动回到主屏可见范围；首次启动默认位置为屏幕右侧偏上、不贴边。

## 三、待办主页

- **顶部时钟**：时间（跟随 12/24 小时制设置，显示精确到分钟）＋ 日期（如"2026年9月21日 星期一"），每秒刷新
- **操作区**：快捷添加按钮（列表左上）、待办计数（X/上限）、批量删除按钮、已完成按钮（列表右上）、「＋」新建按钮（列表右上）
- **事项行**：拖拽手柄 ＋ 内容（超长截断，悬停 1 秒气泡显示全文）＋ 逾期标签（红）＋ 右端勾选框
- 点勾选框＝完成，动画后移入已完成页，逾期标记随之带入
- **双击事项行**（手柄、勾选框除外）＝ 打开编辑窗口；单击不触发任何操作
- **长按手柄拖动**手动调整顺序
- **批量删除**：进入多选模式（右端勾选框原位变为**批量选中示意**——与完成勾选框同款样式，选中＝蓝底白勾并高亮整行；批量模式下拖拽与完成勾选均禁用，拖拽柄置灰保留；底部操作条：已选 N 项 / 全选 / 取消 / 删除所选），**未选中任何事项时「删除所选」按钮置灰不可点（至少选中一项才可删除）**，确认后直接删除（不可恢复）；批量模式下点击事项＝选中/取消选中
- 跨天结算只为逾期事项**添加标签，不改变其在列表中的位置**；新事项始终加入列表末尾
- 新建、模板一键添加、已完成退回均**受待办上限约束**，超限弹提示
- 空列表提示："今日做点什么好呢 / 点击右上角 ＋ 新建一条待办"
- 待办允许相同内容重复创建（查重只针对模板）

## 四、新建 / 编辑事项窗口

**新建（点＋）**：输入框（上限 300 字，带计数器，将满变红）＋「清空」＋「新建事项」按钮（无内容不可用）；创建成功进入待办列表末尾。返回箭头：无输入直接退出，有输入询问"返回将不保存"。

**编辑（双击事项）**：属性区显示**事项状态**（已逾期时红色显示"**已逾期**"；未逾期灰色显示"**进行中**"）与创建时间（始终保留第一次，不可改）；输入框（300 字＋计数＋「还原」，内容改过才可用）；「添加到模板」（受模板上限和查重约束）；「删除」（确认框，删除后不可恢复）；标题栏「保存」（空内容提示"内容不能为空"并不关闭）；返回箭头：内容未改直接退出，已改询问"是否保存"。

## 五、快捷添加页（模板库）

- 标题"模板 · N/10"；「＋」新建、「批量删除」多选（逻辑同主页，直接删除）
- **模板行**：手柄 ＋ 内容（截断气泡）＋ 右端「＋」＝ 一键添加为待办（模板保留，受待办上限）
- **双击模板**＝编辑窗口（创建时间、还原、删除、保存、返回询问，同编辑事项样式）
- 新建模板窗口：说明文字＋输入框（300 字、计数、清空）＋「新建模板」按钮（有内容才可用）
- 模板上限 10 个；相同内容的模板不能重复创建（提示"已存在相同内容"）；支持长按手柄拖动排序
- 底部说明："模板不计入待办数量上限；点击条目右侧 ＋ 可加入今日待办，模板不会消失"

## 六、已完成页（只放当天完成的）

- 标题"已完成 · N"；每行：勾选框（点击＝**反选退回待办**，退到列表末尾并重新计算逾期；受上限）＋ 内容 ＋ 逾期标签（红，仅有逾期时显示）＋ 完成时间
- **双击**＝详情窗口（**纯查看**）：内容、创建时间、完成时间、逾期标签（**未逾期 / 已逾期**，判定：创建日期≠完成日期＝已逾期）＋「关闭」
- 排序按钮：按完成时间正序/倒序切换（默认正序）；此排序设置与历史记录页共用
- 底部「历史记录」按钮；空提示："今天还没有完成的事项"

## 七、历史记录页

- **按天查看**：前一天/后一天按钮 ＋ 日期选择（范围：最早记录日 ~ 今天）＋「回到今天」＋ 当日条数
- 只读浏览；**双击**＝详情窗口（纯查看，内容同已完成页：内容、创建时间、完成时间、逾期标签 未逾期/已逾期 ＋「关闭」）
- **不能退回待办**；可删除：「批量删除」按钮进多选模式（勾一条也可删单条），确认后直接删除
- **导出**：选起止日期 → 通过系统"另存为"对话框保存 CSV（UTF-8），文件名"待办完成记录_起始日_结束日.csv"，列：完成日期、完成时间、事项内容、创建时间、完成时间
- 空提示："该日期暂无已完成事项"

## 八、设置页

1. **待办数量上限**：1~10 条步进调节（默认 10）；**上限不可调至低于当前待办列表数量**——当上限＝当前事项数时减号置灰不可再减，加号最多到 10
2. **时间显示制式**：24 小时制 / 12 小时制
3. **导入历史记录**：通过系统文件选择框选 CSV（只接受本软件导出格式）→ 解析 → 二选一：**覆盖导入**（清空现有全部历史并替换，弹确认框，被清掉的直接消失）/ **合并导入**（两边合并为一份新历史，内容、创建时间、完成时间等属性完全相同的事项只保留当前那条）
4. **开机自启**：开关，默认关闭；自启后直接显示窗口

所有设置即时生效并保留。

## 九、数据规则

- **事项属性**（软件为每条事项存储的数据字段，既驱动下列自动逻辑，也是界面展示信息的唯一来源）：内容（≤300 字）、创建时间、完成时间、逾期标记；**不设"完成状态"字段——有完成时间＝已完成，无完成时间＝待办**
- **逾期判定（统一口径）**：未完成时——创建日期 ≠ 今天 即逾期（每天跨天时自动标记），待办列表行内显示红色"逾期"标签、编辑窗口属性区显示红色"已逾期"；已完成时——创建日期 ≠ 完成日期 即"已逾期"，详情窗口显示逾期标签（未逾期/已逾期），列表行内仅逾期时显示红色标签；从已完成退回待办时重新计算；导入的记录同样按此口径推算
- **跨天结算（全程静默，不弹任何提示）**：运行中自动检测跨过 0 点 → 昨日已完成事项归档进历史、未完成待办全部标记逾期；关机跨天的，下次启动时同样静默补结算
- **导入落位**：完成日期为今天 → 进已完成页；更早 → 进历史归档
- **持久化**：所有改动即时写入本地文件，关闭/重启不丢失；排序、窗口位置、缩放、面板开关、主题、置顶、全部设置均记忆
- **首次启动**：空列表（不带演示数据），显示空状态引导文案；卸载软件不删除数据文件（除非用户手动删）

## 附：v1.3 系统快捷键与窗口语义裁定（2026-10-05/06，用户裁定；仅记录不开发）

> 以下为用户逐条裁定，作为项目需求基线；实现现状与裁定不一致处，待架构讨论清楚后统一修订。

1. **显隐途径收敛**：组件的最小化/显隐仅有 3 条途径——①待办窗口右上角 × 按钮（隐藏到托盘）②双击托盘图标（切换）③托盘右键菜单「显示/隐藏」（切换；恢复=最小化前窗口状态）。
2. **Win+D**：回归系统默认，不做技术干预。未置顶=普通窗口行为（可被隐藏，再按 Win+D 恢复）；置顶=系统天然豁免（置顶层常驻）。
3. **Win+M**：回归系统默认，不做技术干预、不做要求（当前设计下组件不被 shell 窗口枚举，Win+M 无效果属自然结果）；后续出现相关需求再具体修订。
4. **Alt+F4 = 强制退出整个应用（无确认框）**：组件=应用整体口径；任一窗口收到系统关闭→退出应用，退出前数据落盘照走。二级窗自身的 ×/← 按钮关闭仅关自己。
5. **TOOLWINDOW/skipTaskbar 保留**：组件不进任务栏、不进 Alt+Tab（UI 设计决策，2026-10-06 确认）。
6. **置顶语义（2026-10-07 架构讨论定稿）**：未置顶=**普通窗口层级**——不沉底、可激活（点击浮上来获焦点）、被应用覆盖即被覆盖（挂件态/WS_EX_NOACTIVATE/失焦沉底机制已删除）；置顶=浮最上层可激活。
7. **架构心智模型（用户 2026-10-06 声明，待架构讨论确认）**：「3 个一级窗口」指视觉层面；**待办主窗=应用主页、唯一可独立存在的窗口；快捷添加/已完成从属、不可独立存在**。当前三窗分离实现（批次 A/B，为根治单窗缩放抖动而批）与此模型的关系是架构讨论的核心议题。
8. **架构定论（2026-10-07）**：用户对比单窗对照版（v1.0.8）与三窗版后裁定**维持三窗架构**；方案 C 单窗路线关闭。
9. **关联积压处置**：气泡弹窗卡死（已修：veil/失焦即隐藏）、缩进态托盘恢复自动弹出 3 秒（已实施）、标题栏齿轮/图钉换位（已实施）、文本编辑光标失效（自动化环境正常、真机未复现，持续观察）。
10. **开发纪律新增（2026-10-06 用户采纳）**：每批开发前先交一页「体验说明书」（纯用户视角：会看到什么、怎么操作、什么算通过），用户批准后才动代码。


## 附：v1.4 变更记录（2026-10-10，v1.1.0 交付同步；全部经用户逐项真机验收）

> 本节记录 v1.1.0 相对需求文档 v1.3 基线的语义补充与修订（实现细节与验收表见 docs/验收报告.md §十一）。

1. **缩进/弹出形态**：三窗直上直下同帧对齐（无过渡动画）——侧窗透明待机（原地消失、画面保留）、待办窗直切白条（160×12）；用户裁定"同步直上直下不要多余的动作"。
2. **胶囊交互定稿（白条 mouseenter 方案）**：鼠标**碰到白条本体**（垂直 12px/水平 160px）才弹出——mouseenter 为系统真实命中分发，**被其他窗口遮挡时天然不弹**；白条点击为附加弹出途径。主进程不再做缩进态自算判定。
3. **托盘显隐**：三窗统一真隐藏/重新唤醒（无透明待机特判）。
4. **3 秒停留**：缩进态托盘恢复自动弹出并停留 3 秒，到期光标不在组件上则自动缩回白条；二级窗开着时保持弹出+取消计时。
5. **气泡**：独立小窗**透明常驻**（隐藏=透明度 0 而非 hide）——消除显示闪现/闪动。
6. **二级窗口**：统一 3:4 尺寸（420×560）；新增待办输入框长宽 3:1 等比缩放；模态期间侧窗不遮挡二级窗。
7. **开机自启加固**：开启时清除系统启动项禁用标记（修复"开关开着却不启动"）；历史开发版残留自启项已清理。
8. **组件不进任务栏/Alt+Tab**（TOOLWINDOW）；禁用系统窗口过渡动画。
