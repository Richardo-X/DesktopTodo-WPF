## 一、这一版是什么（一句话）

三窗心智原样保留，只把质感推向"摊在桌上的一叠便签"：主窗居中，模板与已完成做成两张圆胖小卡分列左右；
圆角更大、投影更软、行距更松，收起时整组缩成一颗温热的果冻豆。

## 二、你会看到什么

### 2.1 三张便签

| 便签 | 设计尺寸 | 位置 |
|---|---|---|
| **模板便签（左）** | 190 × 自适应 | 主窗左侧、缝隙 14；**默认收起**，点主窗工具区「模板」入口出现 |
| **主窗（中）** | 360 × 640 | 锚点＝主窗左上角；始终可见 |
| **已完成便签（右）** | 190 × 自适应 | 主窗右侧、缝隙 14；默认收起，点主窗工具区「已完成」入口出现 |

> 左右两张便签比主窗略矮、顶端对齐，带轻微错落（左便签顶边比主窗低 6px、右便签低 10px），像摊开的纸。

### 2.2 主窗从上到下

1. **品牌条**：顶部一条 4px 圆角主题色横条（纸的"书脊"）。
2. **标题行**：左侧＝32px 圆角勾标（主题色底 + 白勾）＋「桌面待办」＋下面 11px 小字「今天也要慢慢来」；
   右侧＝五枚工具（主题 / 置顶 / 缩进锁 / 设置 / **收纳**）。
3. **时钟行**：`14:32`（26px，字重 600）＋ 日期 11px 灰字；同一行右端＝计数胶囊 `3/10`。
4. **待办行**：手柄点阵 ＋ 内容（超宽省略）＋ 逾期红字 ＋ **19px 圆角勾选框**（圆角 7）；
   行距 8、行圆角 12、悬停淡淡暖底色。
5. **底部动作**：左「🗑 批量删除」（描边幽灵钮）、右「＋ 新建待办」（主题色实心钮，圆角 12）。

### 2.3 左右两张便签

- **模板便签**：标题「模板 · 2/10」＋ 右上「管理」（打开模板管理/批量）；
  行＝文字 ＋ 右端描边小 `＋`（主题色描边）；底部一行小注「点 ＋ 一键加入今日待办，模板本身保留。」
- **已完成便签**：标题「已完成 · 3」＋ 右上「正序」（点一下切倒序）；
  行＝18px 实心勾（主题色底白勾）＋ 内容 ＋ 右端完成时刻 `11:48`；
  底部小注「点勾可退回待办，末尾重排、逾期重算。」

### 2.4 状态与文案

| 场景 | 你会看到 |
|---|---|
| 待办为空 | 主窗列表区：「今天也要慢慢来」＋「点下面 ＋ 新建一条」 |
| 已完成为空 | 右便签：「今天还没有完成的事项」 |
| 模板为空 | 左便签：「还没有模板，点 ＋ 新建」 |
| 到上限（10 条） | 计数胶囊变主题色；点 ＋ 提示「已达上限」 |
| 逾期 | 标题后红色「逾期」小字；非逾期不显示 |
| 12/24 制 | 24h `14:32`；12h `2:32 PM`（跟随设置） |

### 2.5 收纳与托盘

- 整簇贴屏顶后鼠标离开约 0.5s → 三张便签**整组上滑出屏**；屏顶留一颗 **80×26 果冻豆**
  （圆角 99、主题色描边、内含 3 个 5px 小点），水平居中于组件原位。
- **鼠标碰到豆子** → 豆子消失、三张便签整组滑回。
- 托盘三途径与现版一致；右键「退出」是唯一关闭途径。

## 三、怎么操作验证（真机步骤）

1. **启动**：看到主窗居中；点工具区「模板」→ 左便签出现（顶端比主窗略低）；点「已完成」→ 右便签出现。
2. **新建**：点底部「＋ 新建待办」→ 二级窗（420×560，与主窗中心对齐）→ 输入 ≤300 字 → 确认
   → 新条进列表末尾；计数 +1。
3. **完成**：勾一条 → 该行离开主窗、出现在右便签末行（带完成时刻）；主窗计数 −1、便签标题 +1。
4. **退回**：点右便签某行的勾 → 退回主窗末尾、逾期按今天重算。
5. **排序**：点右便签「正序」→ 切「倒序」（按完成时间反排）；再点切回。
6. **模板**：左便签点行右端 `＋` → 内容进待办末尾、模板保留；双击行改文字；
   「管理」→ 批量删除/新建模板（上限 10、查重）。
7. **批量删除**：点「批量删除」→ 行前出现勾选、整行置灰 → 选 n 条 →「删除所选」→ 确认；「返回」退出。
8. **收纳/弹出**：拖到屏顶 → 松手 → 鼠标移开 → 整组上滑 → 屏顶出现果冻豆 → 鼠标碰豆 → 整组滑回。
9. **缩放**：拖主窗右下角角标 → 三张等比缩放；左右便签分别钉住主窗的左右边缘（缝隙恒定 14）。
10. **其它**：主题/置顶/缩进锁/× 进托盘/Alt+F4/单实例/重启记忆——同现版。

## 四、什么算通过

- §三 的 10 步全部符合，且无闪烁/残影/裁切；
- 三张便签的相对位置在缩放与拖动中恒定（缝隙不变、顶端对齐+错落关系不变）；
- 待办/已完成/模板三段数据与计数每次操作后立刻一致；
- 收纳只由"碰果冻豆"触发；豆子被遮挡时划过不弹；
- 重启后记忆（位置/缩放/主题/置顶/缩进锁/两侧便签开关/已完成排序）全部恢复。

## 六、技术口径（记录，供实施对照）

**令牌（日 / 夜）**：accent `#b06a43` / `#c98d67`；accent-fg `#fff8f3` / `#241a12`；
text `#40382f` / `#efe8df`；muted `#83776a` / `#b3a89a`；faint `#a89c8d` / `#8d8377`；
card `#fbf6ef` / `#27211b`；card-border `rgba(90,70,50,.12)` / `rgba(255,240,225,.09)`；
row-hover `rgba(140,110,80,.07)` / `rgba(255,235,215,.06)`；overdue `#b3403a` / `#d4706a`；
圆角 窗 16 / 行 12 / 控件 9；投影 `0 14px 40px rgba(90,60,30,.20)`；时钟 26px / 字重 600；
正文 13 / 小注 11 / 逾期 10；主窗 360×640、侧便签 190 宽、缝隙 14、错落 6/10px。

**机制**：

1. **三窗不变**：仍为三个独立窗口（模板左 / 主窗中 / 已完成右），已完成仍是独立便签（与现版结构一致，
   只是尺寸与位置关系换新）——这是 2A 与 1C 最大的结构差异。
2. **左右便签缩放**：沿用已真机验证的"固定画布 + 卡面渲染层缩放"；
   左便签**右缘钉主窗左缘 − 14**（卡面右上角对齐，向右不溢出）、右便签**左缘钉主窗右缘 + 14**
   （卡面左上角对齐）——两侧镜像同一套机制。
3. **收纳**：独立小窗 80×26（圆角 99、3 点、主题色描边），真实命中。
4. **已完成排序**：用现成 `DoneSort`（正序/倒序）字段，不吃新数据。

**影响面**：`ClusterLayout`（侧窗宽度 190、缝隙 14、错落偏移）、`ClusterController`（三窗摆放 + 收纳条）、
`Themes/*`（整套暖色令牌 + 圆角/投影/字重），三窗 XAML 全部重做。`TodoWpf.Core` 不动。
