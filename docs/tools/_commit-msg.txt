fix(C4): 发布脚本接入 GitHub 上传（实测端到端通过）+ 四处踩坑

publish-release.ps1：
- vpk pack 加 --noPortable（便携版不做）。不能用"打包后删 zip"代替——
  vpk upload 仍按清单去找 Portable.zip，缺失即上传失败（实测）
- 上传前若同名 release 还是草稿（上次中途失败留下）先删掉重建；
  用 gh release list 而非 gh release view（后者在 release 不存在时会往 stderr 写错误，
  在 ErrorActionPreference=Stop 下被当成异常中断）
- 自建安装器以 ASCII 名上传（DesktopTodoWPF-Setup-<ver>.exe）：
  中文名经 shell 传参会乱码（实测上传成了 WPF-.exe）
- 空仓库无法创建 Release（GitHub 限制）→ 已给发布仓库加 README 使其非空

实测（端到端）：装 1.2.3 → 发 1.2.4 到 GitHub → 应用启动检查发现新版本、标题栏出现
「有新版本！」→ 点它 → 「重启完成更新」→ 20 秒内更新完成并自动重启到 1.2.4（走增量包）。

环境事实：本机直连 github.com 超时，但 api.github.com 与 objects.githubusercontent.com 可达，
检查与下载实际走后者故可用；若用户网络完全不通 GitHub 则需换源（可在设置页关闭更新提示）。
