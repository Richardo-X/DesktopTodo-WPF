## 一、这一版是什么（一句话）

待办和已完成收进**同一张卡**，中间用一条"现在"分开；模板系统独立成一张小窗。整张卡像一页安静的日程纸：
上面是还没做的，下面是今天已经做完的（带完成时刻），模板要用时才叫出来。

## 二、你会看到什么

### 2.1 两张卡

| 卡片 | 设计尺寸 | 位置与显隐 |
|---|---|---|
| **主窗** | 360 × 640 | 锚点＝主窗左上角（缩放/拖动的不动点）；始终可见 |
| **模板窗** | 260 × 640（内容自适应，最大 640） | 贴主窗**右侧**、缝隙 4；**默认收起**，点主窗左柱 ⚡ 出现/收起 |

### 2.2 主窗从上到下

1. **标题行**：左侧＝方块勾标（16px 圆角色块 + 白勾）＋「桌面待办」；右侧＝五枚窗口图标
   （主题 / 置顶 / 缩进锁 / 设置 / 关闭）。
2. **动作区（三列一行）**：
   - 左柱：`⚡` 描边方钮（显隐模板窗）＋ 计数胶囊 `5/10`（待办条数/上限）；
   - 中部：**大号时钟 29px**（等宽数字）＋ 下面一行日期 10.5px 灰字；
   - 右柱：`🗑 批量删除` 描边胶囊 ＋ 蓝色方形 `＋`（新建待办）。
   - **已完成不设开关**（它就在下方，不需要开关）。
3. **待办区**（空心点，无时刻）：
   每行＝手柄点阵（拖动排序）＋ 内容（超宽末尾省略）＋ 逾期红字（仅逾期项）＋ 白色勾选框 16px；
   顺序＝数据顺序（新建的加末尾）。
4. **"现在"分隔**：左侧小字「现在」＋ 轴上刻度 ＋ 右侧虚线；它把"还没做"和"已做完"分开。
5. **已完成段**：小标题「已完成 · n」＋ 每行＝完成时刻 `HH:mm`（左列）＋ 实心点 ＋ 内容 ＋ 已勾选框；
   点已完成行的勾＝退回待办。

### 2.3 模板窗

- 标题「模板 · 2/10」＋ 右上 `×`（收起）。
- 行＝文字 ＋ 右端小 `＋`：点 ＋ 把该模板**原样加入今日待办末尾**（模板保留；待办已满先提示）。
- 底部：「＋ 新建模板」「批量删除」（模板的多选删除）。
- 双击行＝改文字；新建/编辑模板走二级窗（上限 10、同内容查重）。

### 2.4 状态与文案

| 场景 | 你会看到 |
|---|---|
| 待办为空 | 待办区中间：「今天还没有待办」＋「点右侧 ＋ 新建一条」 |
| 已完成为空 | 已完成段：「今天还没有完成的事项」 |
| 模板为空 | 模板窗：「还没有模板，点 ＋ 新建」 |
| 到上限（10 条） | 计数胶囊变主题色；点 ＋ 提示「已达上限」 |
| 逾期 | 标题后红色「逾期」小字（10px）；非逾期不显示 |
| 12/24 制 | 跟随设置：24h 显示 `14:32`，12h 显示 `2:32 PM` |

### 2.5 收纳与托盘（沿用现版语义，只换外观）

- 整簇贴到屏幕顶边后鼠标离开约 0.5s → **两张卡保持对齐、整组上滑出屏**（≈0.18s）；
  滑完屏顶留一条 **48×3 主题色细线**（水平居中于组件原位）。
- **鼠标碰到细线** → 细线消失、整组滑回原位（被其他窗口挡住时不弹）。
- 托盘三途径不变（主窗 ×／双击托盘／托盘右键「显示、隐藏」）；右键「退出」是唯一关闭途径。

## 三、怎么操作验证（真机步骤）

1. **启动**：看到两张卡（模板窗默认收起）；点左柱 `⚡` → 模板窗在主窗右侧出现，再点收起。
2. **新建**：点右柱蓝色 `＋` → 二级窗（420×560，与主窗中心对齐）→ 输入 ≤300 字（带计数）→「新建」
   → 新条进待办末尾；计数 +1；空内容不可提交。
3. **完成**：勾一条待办 → 该行**从待办区消失**、出现在"现在"下方已完成段末行（显示完成时刻 HH:mm）；
   待办计数 −1、已完成 +1。
4. **退回**：点已完成行的勾 → 退回待办末尾，逾期按今天重算（计数反向变化）。
5. **逾期**：昨天创建、今天还没完成的项 → 标题后红字「逾期」；今天创建的不显示。
6. **模板**：模板窗点某行右端 `＋` → 内容进待办末尾、模板仍在；双击行 → 改文字；
   「＋ 新建模板」（上限 10、查重）；「批量删除」多选删除。
7. **批量删除待办**：点右柱「批量删除」→ 每行前出现勾选、整行置灰 → 选 n 条 →「删除所选」→ 确认；
   「返回」退出批量态（重复点「批量删除」＝清空重来）。
8. **收纳/弹出**：把整簇拖到屏幕最顶 → 松手 → 鼠标移开 → 整组上滑；
   屏顶出现 48×3 细线 → 鼠标碰细线 → 整组滑回。
9. **缩放**：拖主窗右下角角标 → 两窗等比缩放：主窗左上角不动；模板窗**左缘钉主窗右缘 + 4**、
   向右伸展；缩到最小时内容完整。
10. **其它**：标题栏月亮切日/夜（记忆）；图钉切置顶（记忆）；× 进托盘；Alt+F4 直接退出（先落盘）；
    再开一次 exe 不会出第二个（唤起现有）；关掉重开 → 位置/缩放/主题/置顶/缩进锁恢复。

## 四、什么算通过

- §三 的 10 步全部符合，且无闪烁/残影/裁切；
- 待办/已完成/模板三段的数据与计数**每次操作后立刻一致**（与 165 条 Core 单测口径一致）；
- 逾期红字只出现在逾期项；12/24 制切换正确；空态/上限提示正确；
- 收纳/弹出只由"碰细线"触发；细线被遮挡时划过不弹；
- 重启后记忆（位置/缩放/主题/置顶/缩进锁/模板窗开关）全部恢复。

## 六、技术口径（记录，供实施对照）

**令牌（日 / 夜）**：accent `#5b7a99` / `#7e97ad`；accent-fg `#f6f8fa` / `#10151b`；
text `#3a3f46` / `#d9dde2`；muted `#6d737b` / `#9aa2ac`；faint `#9aa0a8` / `#767d86`；
card `#f7f8f9` / `#1d2127`；card-border `rgba(30,35,42,.10)` / `rgba(255,255,255,.08)`；
row-hover `rgba(30,35,42,.045)` / `rgba(255,255,255,.05)`；line `rgba(30,35,42,.22)` / `rgba(255,255,255,.18)`；
overdue `#b3403a` / `#d4706a`；done-time `#9aa0a8` / `#767d86`；
圆角 窗 8 / 行 6 / 控件 6；投影 `0 6px 24px rgba(16,24,34,.16)`；时钟 29px / 字重 500（等宽数字）；
正文 12.5 / 小注 10.5 / 逾期 10。

**几何**：主窗 360×640；模板窗 260 宽（高 ≤640）；缝隙 4（不随缩放）；
缩放下限 0.7、上限沿用现版公式（半屏高 / 工作区宽）；
锚点＝主窗左上角，模板窗**左缘**＝锚点 + 主宽 + 4（与现版"右缘钉"镜像）。

**机制复用**：

1. **删一窗**：原"已完成窗"不再创建，已完成并进主窗下半段（Core 的 `DoneRows` 直接喂同窗 ItemsControl）。
2. **模板窗**：镜像已真机验证的"快捷窗固定画布"方案——窗口矩形恒定（画布＝设计尺寸 × 缩放上限），
   卡面固定设计尺寸、**左上角对齐画布左上角**、渲染层 `transform: scale()`（WPF `RenderTransform`，
   origin 左上）表现大小；缩放时窗口矩形零变化 ⇒ 无拖影/无慢半拍。
3. **收纳**：白条窗换 48×3 细线（独立窗、真实命中）；
4. **已完成段**：段内行复用待办行的样式（只换左侧时刻列 + 已有勾选态）。

**影响面**：`ClusterLayout`（少一窗、模板窗钉左缘）、`ClusterController`（布局/摆放两处路径）、
`App`（少建一窗）、三窗的 XAML（主窗重做、模板窗重做、删已完成窗）、`Themes/*`（令牌 + 控件样式全换）。
`TodoWpf.Core` 不动。
