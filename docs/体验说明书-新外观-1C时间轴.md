## 一、这一版是什么（一句话）

待办和已完成收进**同一张卡**，中间用一条时间轴分开；模板系统独立成一张小窗，要用时才叫出来。整张卡像一页安静的日程纸。

## 二、你会看到什么

### 2.1 两张卡

| 卡片 | 尺寸 | 位置与显隐 |
|---|---|---|
| **主窗** | 宽 360；高度可调，默认按屏幕一半在 448 到 640 之间 | 锚点＝左上角；始终可见 |
| **模板窗** | 宽 260；高度随内容，最多 448（满 10 条） | 贴主窗**右侧**、缝隙固定 4；默认收起，点主窗 ⚡ 显隐 |

### 2.2 主窗从上到下

1. **标题行**：方块勾标 +「桌面待办」；右侧五枚图标（主题 / 置顶 / 缩进锁 / 设置 / ×）。
2. **时钟**：28px 等宽数字 + 日期。
3. **动作行**：计数胶囊（如 `5/10`）、批量删除、＋ 新建、⚡ 模板窗；批量态时整行让位给同高的批量条。
4. **待办段**：白卡行，行高 34；每行＝拖拽点阵 + 内容（超宽省略）+ 逾期红字 + 勾选框。
5. **已完成段**：小标题「已完成 · n」+ 排序按钮（在横线右端）+ 时间轴；每行＝完成时刻 + 实心点 + 内容 + 勾选框。

### 2.3 模板窗

- 标题只有「模板」；没有 ×，显隐只靠主窗 ⚡。
- 动作行：计数胶囊、＋ 新建、批量删除（贴最右）。
- 行是**纯文本**，行尾 `＋` 把该模板加入今日待办；双击改文字。
- 批量态：勾选框出现在行尾 `＋` 的位置，内容不位移；批量条与主窗同构，按钮顺序为「已选 n 项 · 删除所选 …… 全选 · 返回」。

### 2.4 详情窗（已完成 / 历史）

- 标题栏：左侧返回箭头、居中标题（「已完成事项」/「历史事项」）、右侧删除。
- 三行属性：创建时间 / 完成时间 / 状态。
- 1px 分隔线。
- 正文无框直铺。
- 默认 420×438；纯查看，删除需确认。

### 2.5 设置页与历史页

- **设置**：待办上限（1 到 10，不可低于当前待办数）、12/24 小时制、历史入口、CSV 覆盖/合并导入、开机自启、版本号。分组之间有 1px 分割线。
- **历史**：日期导航（前一天 / 后一天 / 回到今天 / 日期选择）、按完成时间排序、批量删除、CSV 区间导出、双击看详情。功能已定稿，不再增删。

### 2.6 状态与文案

| 场景 | 你会看到 |
|---|---|
| 待办为空 | 单行占位：「今天还没有待办」+「点 ＋ 新建一条」，不顶动已完成段 |
| 已完成为空 | 「今天还没有完成的事项」 |
| 模板为空 | 「还没有模板，点 ＋ 新建」 |
| 到上限 | 计数变主题色；点 ＋ 提示已达上限 |
| 逾期 | 行内红色「逾期」；详情属性行状态标红 |
| 12/24 制 | 跟随设置即时切换 |

### 2.7 批量态规则

- 主窗与模板窗**二选一**，同一时间只有一个窗处于批量态。
- 目标窗只冻结「设置」按钮；主题、收纳仍可用。
- 另一个窗整窗降透明并禁用指针。
- 已完成段暂不参与批量；悬停气泡不抑制。
- 最小化到托盘时立即退出批量态。

### 2.8 缩放、高度拖拽、收纳、托盘

- **等比缩放**：主窗右下角手柄；模板窗跟随，左缘始终＝主窗视觉右缘 + 4。二级窗四组各自独立。
- **高度拖拽**：主窗底边；只改竖向长度、宽度不变。模板窗**不跟随高度**，只跟随缩放。主窗最小高度＝模板满 10 条时的自身高度（448）。
- **滚动条**：全应用 3px 细条，永久预留槽位，出现或消失都不挤压内容。
- **×**：最小化到系统状态栏（并退出批量态），不是退出程序。
- **贴边缩进**：只在主窗顶边碰到屏幕上边缘时触发；缩进后屏顶留一条细线，鼠标碰到恢复。
- **托盘**：双击托盘图标恢复；右键「显示/隐藏」「退出」；退出是唯一结束程序的途径。

### 2.9 窗口外壳

- 系统外壳、不透明、Win11 系统圆角（8px）。
- 阴影暂不处理。
- 保留双击标题栏最大化、拖到屏幕边缘吸附、右键系统菜单。
- Win10 上为直角降级。

## 三、怎么操作验证（真机步骤）

1. **启动**：看到主窗（模板窗默认收起）；点 ⚡ 模板窗在右侧出现，再点收起。
2. **新建**：点 ＋ → 编辑窗 → 输入 ≤300 字 → 保存；新条进待办末尾，计数 +1。
3. **完成**：勾一条待办 → 从待办段消失、出现在已完成段末行（显示完成时刻）。
4. **退回**：点已完成行的勾 → 退回待办末尾，逾期按今天重算。
5. **排序**：拖点阵上下移动，其余行动画让位；拖过文字不会选中。
6. **批量**：点批量删除 → 每行出现勾选 → 选 n 条 → 删除所选 → 确认；返回退出。
7. **模板**：点行尾 ＋ 加入待办；双击改文字；模板批量删除的勾选框在原 ＋ 位置。
8. **详情**：双击已完成事项 → 三行属性 + 分隔线 + 无框正文；点删除 → 确认后移除。
9. **设置**：改上限、切 12/24 制、打开历史、导入 CSV、开关开机自启。
10. **历史**：翻日期、切排序、批量删除、导出 CSV、双击看详情。
11. **缩放**：拖右下角 → 两窗等比；拖主窗底边 → 只有主窗变高，模板窗不动。
12. **收纳**：把主窗拖到屏幕顶边 → 鼠标离开 → 整组上滑；碰顶部细线恢复。
13. **最小化**：点 × → 进托盘；双击托盘图标恢复；重复启动不会出第二个实例。

## 四、什么算通过

- §三 的 13 步全部符合，无闪烁、残影、裁切；
- 待办/已完成/模板三段的数据与计数每次操作后立刻一致；
- 滚动条出现或消失时内容不左右跳；
- 批量态规则符合 §2.7；
- 重启后记忆（尺寸、缩放、主题、置顶、缩进锁、模板窗开关）全部恢复。

## 五、本批不动的

- `TodoWpf.Core` 的任何逻辑与数据文件格式；
- CSV 导入导出、设置项、历史页的功能范围（已定稿，只换视觉）；
- 旧 Electron 项目只读，不改。

## 六、技术口径（记录，供实施对照）

- **令牌**：以原型 `:root` 与 `body[data-theme=night]` 为准（日间 shell `#eef1f6`、行卡 `#ffffff`；夜间 shell `#171a1f`、行卡 `#252930`）。
- **圆角阶梯**：窗 10 / 行 8 / 控件 6。
- **字号**：10 / 11 / 13 / 28 四档；正文 13、行高 1.8。
- **行高**：待办行与已完成行均 34；已完成段时间轴竖线随节点中心对齐。
- **尺寸**：主窗 360 宽、高度 448 到 640（默认按屏幕一半）；模板窗 260 宽、最高 448；二级窗 420×560，详情 420×438。
- **缩放**：主窗 0.7 到 1.15，二级窗 0.7 到 1.4；超屏只计算主窗。
- **持久化**：只存缩放倍数与布局高度，不存屏幕坐标；启动与换屏时按当前工作区重钳。
- **已知待落地验证**：缩放与高度拖拽的内容抖动、1px/2px 细线在非整数倍数下的漂移、字体渲染与字距。
