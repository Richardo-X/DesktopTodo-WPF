# 批次 04 · 主窗替换（外壳 + 尺寸 + 静态布局）· 体验说明书

| 项目 | 内容 |
|---|---|
| 批次 | 04 主窗替换 |
| 范围 | 窗口集合 3→2；主窗外壳、尺寸规则、静态布局与视觉令牌 |
| 不做 | 模板窗内容、二级窗、批量态、历史/设置、业务接线 |
| 依据 | 原型 `1C-时间轴-可交互.html`；尺寸规则 `规格-窗口尺寸与缩放.md` |

## 你会看到什么

1. **只剩一张主窗**：快捷窗、已完成窗不再出现；模板窗本批不出现。
2. **主窗 360 宽**，默认高度按屏幕工作区一半，夹在 448 到 640 之间。
3. **系统外壳**：不透明、Win11 系统圆角；阴影本批不做。
4. **两个手柄**：底边拖高度（只变高，最小 448）、右下角等比缩放（0.7 到 1.15）。
5. **新配色**：日间外壳 `#eef1f6`、待办行白卡 `#fff`；夜间 `#171a1f` / `#252930`。
6. **主窗布局按原型**：标题行、时钟、动作行、待办段、已完成段（时间轴）。
7. **数据仍是真实数据**：从现有 Core 读取，勾选完成、计数同步。

## 怎么验证

1. 启动：只有一张主窗，宽 360，高度符合屏幕一半规则。
2. 拖底边：只变高，宽度不变，最小停在 448。
3. 拖右下角：整体缩放，内容跟着缩放，窗口不出屏。
4. 勾一条待办：进已完成段，显示完成时刻，计数变化。
5. 关掉重开：尺寸、缩放、主题恢复。
6. 改系统缩放或分辨率：窗口自动压回可见范围。

## 什么算通过

- 只有主窗、尺寸规则正确、两个手柄手感正常、无裁切与抖动；
- 行高 34、白卡、时间轴、新配色与原型一致；
- 数据与计数正确，重启恢复；
- `dotnet build` 0 错误、`dotnet test` 全绿。

- 托盘、单实例、多屏钳制；
- 模板窗、二级窗（后续批次）。
