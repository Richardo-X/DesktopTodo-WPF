# 验收记录 · 新外观原型（1C 时间轴）

> 验收口径：由用户在真机（Edge 打开 `docs/参考/新外观原型/1C-时间轴-可交互.html`）逐项操作后给出的结论。
> 开发侧自检（Playwright 量尺寸、截图）只作交付前筛查，**不算验收**，也不能推翻用户结论。

## 2026-10-30 · 第一轮原型验收

### 通过

| 项目 | 结论 |
|---|---|
| 等比缩放（主窗与模板窗联动；二级窗四组各自独立） | **通过** |
| 下边框高度拖拽（主窗 448 起；二级窗按组共享高度） | **通过** |
| 模板窗批量删除（批量条与动作行同构、勾选框原位替换 ＋） | **通过** |
| 详情页单条删除（已完成 / 历史） | **通过** |
| 设置页、历史记录页 | **通过** |

### 本轮定稿

1. **历史页功能范围定稿**：日期导航（前一天 / 后一天 / 回到今天 / 日期选择）、按完成时间排序切换、批量删除（全选·取消全选·删除所选）、CSV 区间导出、双击查看详情、空态文案。此后不再增删功能，只调视觉与手感。
2. **已完成段的批量删除：不做**。
3. **主题跟随系统：暂不做**；只保留标题栏的手动日/夜切换。
4. **气泡规格**：水平固定 **280**；垂直随内容增减（同模板窗逻辑）；整体跟随主窗等比缩放，幅度先按 **1:1**，真机再调。
5. **2A 三便签原型：不做**（直接进入 WPF 讨论）。
6. **窗口外壳**：系统外壳（Win11 系统圆角）；阴影暂不处理；保留双击最大化、贴边吸附、右键系统菜单。详见 `docs/规格-窗口尺寸与缩放.md`。

### 待验收（本轮改动）

1. 气泡宽度 280、跟随主窗等比缩放（主窗 1.15 时气泡视觉宽约 322）。
2. 历史页动作行与批量条等高切换，列表不上下跳。
3. 历史页排序按钮在批量态不消失、不挪位。
4. 历史批量条按钮顺序：`已选 n 项 · 删除所选 …… 全选 · 返回`。

### 已知未解决（不计入验收）

| 问题 | 状态 |
|---|---|
| 等比缩放 / 高度拖拽时内容抖动 | 浏览器渲染特性；v2.36 已回退尝试过的缓解，留待 WPF 落地验证 |
| 系统外壳没有可见阴影 | 已决定暂不处理 |
| 1px/2px 细线在非整数倍数下是否漂移 | 留待 WPF 验证 |

## 2026-10-30 · 第二轮原型验收

### 通过

| 项目 | 结论 |
|---|---|
| 气泡 280 宽、跟随主窗等比缩放（1:1） | **通过** |
| 历史页动作行与批量条等高切换，列表不上下跳 | **通过** |
| 历史页排序按钮在批量态不消失、不挪位 | **通过** |
| 历史批量条顺序 `已选 n 项 · 删除所选 …… 全选 · 返回` | **通过** |
| 灰壳 + 白行卡 + 白输入区的明度层级（v2.41） | **通过** |
| 待办行照 Electron 规格：高 44、悬停变主题色边框（v2.42） | **通过** |
| 行内边距 上下 3 / 左右 8、行高自适应最小 34（v2.49） | **通过** |
| 拖拽点阵可见左缘与勾选框右缘对齐（v2.50） | **通过** |

### 本轮新增定稿

1. **全应用滚动条统一 6px 细条**（原 8px 偏粗），且**出现/消失不得改变布局**：
   每个滚动容器永久预留槽位（`overflow-y:scroll`），右侧内边距同步让出等量宽度；
   覆盖主列表、模板列表、设置页、详情正文、历史列表、编辑输入框（v2.51）。
2. 输入框也纳入同一规则（原为系统原生滚动条，会挤压文字）。
3. 卡片到窗口左右边缘各 13px：左边 1 边框 + 12 内边距；右边 1 边框 + 6 内边距 + 6 滚动条槽位。

### 待验收（本轮改动）

1. 6px 滚动条粗细是否合适（主窗列表）。
2. 各窗口滚动条出现/消失时，内容是否不再左右跳（模板窗、设置、历史、详情、编辑框）。
3. 编辑输入框内的滚动条是否不再挤压文字。

2. 用户验收后，把结论追加到本文件的对应日期下（通过 / 不通过 / 部分通过）；
3. 未通过的项目按 AGENTS.md 第 1 条处理：先干净回退，再谈下一步。
