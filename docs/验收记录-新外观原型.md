## 2026-10-30 · 第三轮

### 结论

| 项目 | 结论 |
|---|---|
| 输入框滚动条 | **暂时通过**（有轻微抖动，无明显挤压；后续可再优化） |
| 主窗滚动条 6px 粗细 | 未通过，要求改为 **3px** → 已改 |

### 本轮修复与定稿

1. **设置页分割线在出现滚动时消失**：原因是内容区为 flex 纵列，1px 分割线默认可收缩、被压成 0；
   已给分割线与所有分组项加 `flex:none`（v2.52）。
2. **全应用滚动条统一 3px**（v2.53）；右侧内边距按 3px 槽位重算，内容总宽不变。
   真机实测滚动条实际渲染 2px，各容器在两种状态下内容宽度仍一致。
3. **编辑窗重排**（v2.54）：状态胶囊、聚焦光环、计数右对齐、独立底栏 + 整宽分隔线、
   次要动作用幽灵按钮、主按钮实心主题色、删除为红色幽灵，按钮统一 30px 高。

### 结论（2026-10-31 用户验收）

第三轮全部通过：设置页分割线、3px 滚动条、编辑窗新布局（状态胶囊/聚焦光环/计数/底栏）。
第四轮（编辑窗顶行合并、底栏去分隔线、按钮位置重排 v2.55、三档按钮 v2.56）通过。

### 本轮改动（v2.57）

1. **删除确认框不显示事项内容**：编辑窗待办/模板、详情窗三处确认框去掉内容 body，只保留标题确认。
2. **添加到模板改为两步**：先做判定（空内容 / 上限 / 重复 → 直接 toast 不弹框），通过后弹"添加到模板？"确认框，确认才写入。

### 结论（v2.57，2026-10-31 用户验收）

四条全部通过：删除确认框无内容、添加到模板确认流程与三种拦截、详情窗删除确认、确认框正文文案。

### 本轮改动（v2.58）

**确认框位置**：从"整个浏览器视口居中"改为"对齐打开它的那个窗口的中心"，计算后夹进视口（四边留 8px）。
定位基准优先取当前焦点按钮所在窗口（`.dlg` / `.win`），其次已打开的二级窗，最后主窗。

### 待验收（本轮改动）

1. 编辑窗点「删除」或「返回」：确认框应出现在编辑窗正中，而不是偏到屏幕另一侧。
2. 主窗点「重置演示数据」：确认框对齐主窗中心。
3. 模板窗批量删除、历史窗批量删除：确认框各自对齐所在窗口中心。
4. 窗口靠边或屏幕较小时，确认框不出屏（离边至少 8px）。
