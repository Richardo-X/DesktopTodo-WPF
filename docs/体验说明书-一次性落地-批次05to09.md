## ① 主窗交互

### 1.1 列表拖拽排序
- 操作：按住行首**点阵**上下拖动；其余行让位滑动；松手落位。
- 通过：被拖行跟手浮起（有阴影），落位后顺序立即生效并落盘，重启保持。

### 1.2 批量态
- 操作：点动作行**垃圾桶**进入批量态；动作行原位换成批量条（已选 n 项 / 返回 / 全选 / 删除所选）；点行尾勾选框选中（行变淡底、框变实心）；「全选」切换；「删除所选」删除并退出批量态；「返回」退出。
- 通过：
  - 批量条与动作行**同位等高切换**，窗口高度不跳；
  - 「已选 n 项」计数实时；无选中时「删除所选」置灰；
  - 删除后数据落盘、计数胶囊同步；
  - 批量态下**模板窗整窗冻结**（可读不可点），标题栏设置按钮置灰。

### 1.3 滚动条
- 通过：视觉 3px、命中区 8px；列表不溢出时整条透明；溢出时出现且**不挤压内容**（文字不横向跳动）。

## ② 模板窗交互

### 2.1 常规
- 操作：行尾 **＋** 加入今日待办；**双击行**编辑；标题行 **＋新建** 打开模板编辑窗。
- 通过：加入后今日待办即时出现；编辑保存后模板窗**增量刷新不闪烁**；满 10 条时计数胶囊变强调色、新建置灰。

### 2.2 批量删除
- 操作：动作行**垃圾桶**进入模板批量条（计数缩写 / 全选 / 删除所选 / 返回，按钮贴右）。
- 通过：与主窗批量态同构；删除后模板窗高度即时自适应（rows×36+88）。

## ③ 二级窗四组（均居中于主窗当前视觉矩形）

### 3.1 编辑窗（待办 / 模板共用，三档按钮）
- 操作：待办双击 / 模板双击 / ＋新建 打开；输入正文；保存 / 取消 / 删除。
- 通过：字数上限校验（150 字）；保存后列表即时刷新；删除有确认框。

### 3.2 详情窗（方案 H：420×438）
- 操作：点**已完成**行打开（只读）。
- 通过：标题栏右侧删除；三行属性（创建 / 完成 / 状态）+ 1px 分隔线 + 无框正文。

### 3.3 设置窗
- 操作：标题栏**齿轮**打开。
- 通过：日/夜主题切换即时生效并落盘；24/12 小时制切换时钟即时变化；「恢复默认尺寸」按当前屏重算。

### 3.4 历史窗
- 操作：从设置或入口打开。
- 通过：按完成日期分组；显示归档条目；只读。

### 3.5 确认框（D 类）
- 通过：340 × 内容高、居中；确认 / 取消行为正确。

## ④ 系统行为

### 4.1 托盘
- 操作：标题栏 **×** → 整组隐藏到系统托盘；托盘单击恢复；托盘右键菜单（显示 / 退出）；Alt+F4 直接退出（先落盘）。
- 通过：隐藏后任务栏与桌面无残留；恢复后位置尺寸与退出前一致。

### 4.2 顶边缩进（R1）
- 操作：整组贴屏顶并停留 → 整组上滑隐藏、顶部出现**白条**；指针命中白条 → 整组滑回。
- 通过：动画顺滑；缩进锁定（**锁**图标）开启时贴顶常驻不回弹；解锁恢复。

### 4.3 窗口行为
- 通过：双击标题栏最大化（Windows 11 系统圆角）；右键标题栏系统菜单；拖到屏幕边缘吸附。

### 4.4 跨天结算
- 操作：跨天后首次启动 / 日期变化时自动结算。
- 通过：完成日期 ≠ 今天的已完成项归档进历史；今日列表、计数、已完成段同步刷新。
