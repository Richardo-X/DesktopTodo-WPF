## 六、当前未决问题（按优先级）

### 1. 时间轴容器线对齐（立即修）
当前用 `Margin="41,17,0,17"` 硬算列 1 中心，与行内列宽取整有偏差。**改法**：外层 Grid 内放一个覆盖层 Grid，列定义与行内完全一致（`34 / 16 / * / 16`），`Border Grid.Column="1" Width="2" HorizontalAlignment="Center" Margin="0,17,0,17"`，放在 `ItemsControl` 之前（下层，节点覆盖线）。

### 2. 行间距改 4px（立即修）
`RowCard` 样式 `Margin="0,4"` → `0,2`（相邻间距 4、行节奏 38）。若用户意指“每行上下各 4”，则保持 `0,4` 不变——需确认。当前按“相邻 4”执行。

### 3. 缩放首次拖拽突缩（需用户拍板）
- **根因**：控制器仍用旧 `ClusterLayout.ClampScale`，上限 = `min(工作区高÷2÷640, 工作区宽÷624)`，把“半屏”当**硬上限**。工作区高 < 1280 时上限 < 1，首次拖拽 `scale` 从 1.0 被钳到上限 → 窗口瞬间缩。
- **文档规则**（`docs/规格-窗口尺寸与缩放.md`）：默认高度 = `clamp((工作区高−24)÷2, 448, 640)`，**半屏只是出厂尺寸，不是硬上限**；硬上限 = 倍数 0.7~1.5（1.5 暂定）、布局高 ≤ `(工作区高−24)÷倍数`。
- **修法**：控制器切 `PanelLayout` + `DefaultMainHeight`（批次 04 剩余 B1/B2）。
- **需拍板**：
  - **C2 高度持久化**：A 新增 `UiState.MainLayoutHeight`（合规格 §8）；B 先不持久化、每次按公式算。
  - **C3 首启高度**：接入公式后 1080p 工作区默认高 ≈ 508，不再固定 640。是否接受？

### 4. 图钉颜色（已修待验）
`FindResource` 返回固定画笔实例，主题切换不更新；已改为 `DynamicResource` + `ClearValue`。

## 九、踩坑记录（本会话新增）

- **WPF `Border.CornerRadius` 超大时 X/Y 独立截断**：`99` 在 24 高、40 宽下变成 20×12 椭圆角，拼成椭圆；胶囊必须写**半高**（12）。
- **WPF `Path Stretch="Uniform"` 会把几何填满盒子**，不等于 SVG `viewBox`；必须 `Viewbox + Canvas 24`，否则图标偏大 60~70%、线宽偏粗。
- **`FindResource` 取到的是固定画笔实例**，主题切换不更新；需要跟随主题的必须用 `DynamicResource`，代码覆盖后要 `ClearValue` 恢复。
- **工具调用格式必须 EPSE**，任何简化/DSML 前缀都会失败。
- **Git Bash 里内联 PowerShell 的 `$` 会被吃掉**，用单引号包命令或写 `.ps1` 文件。
- **同一文件多处替换用 python 脚本**：写 temp、按文件分支、逐处 `count` 报告，全中才写（避免半改）。
- **应用运行时会锁 exe**，build 前先 `taskkill //F //IM TodoWpf.exe`。
- **脚本改文件后 Edit 工具缓存会过期**，需重新 Read 再 Edit。
- 截图在本会话看不到像素，只能用像素采样 / UIAutomation / 数值解析自查；`UIAutomation` 对 `ShowInTaskbar=False` 窗口可能找不到元素。
