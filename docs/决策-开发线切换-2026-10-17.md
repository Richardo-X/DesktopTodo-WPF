# 决策：开发线切换（2026-10-17 用户裁定）

## 一、决定

1. **主线暂停**：WPF 版"照搬 Electron 样式"的开发线（`main`）即日起暂停。
   理由：Electron 版已存在且可用，**不需要** WPF 再做它的克隆。
2. **转支线**：WPF 版在**支线分支 `new-look`** 上，从"新样式外观"重新开发——
   底层能力继承，视觉层重做。
3. **暂停点标记**：`tag pause/main-ele-style-2026-10-17` = `main@ef52e83`。
   需要回到旧外观的可用状态时，从该 tag 恢复。

## 二、支线继承什么（不重写，继续使用）

- `TodoWpf.Core` 全量：数据模型 / 仓储（原子写、防抖、损坏留档）/ 逾期与跨天结算 /
  CRUD 服务 / 展示投影 / 批量状态机 / 模板上限（伴随 165 条单元测试）。
- 窗口行为：三窗簇几何（主 470 / 侧 310 / 高 640、缝隙 4、缩放下限 0.7 与上限公式）、
  快捷窗"固定画布 + 渲染层缩放"、缩进/白条、置顶、托盘、单实例、跨 DPI。
- 接线：三窗真实数据绑定、CRUD/批量/模板二级窗、12-24 小时制时钟、计数与空态。

## 三、支线要替换什么（新外观）

- 视觉层：颜色/字号/圆角/间距令牌、`Themes/Controls.xaml` 控件样式、三窗与二级窗的观感、
  图标。
- 布局骨架**待评估**：默认保留"三窗并排 + 缩进白条"（已真机验证的窗口行为），
  是否改布局模型在新外观选型时一并决定。
- 设计基准变更：`docs/参考/交互原型-v3.4-L1.html` 是**旧外观**的权威基准，
  新外观不再以它为准；新基准随选型确定后另行落档。

## 四、随行未完成项（在新外观下重新排期）

- 逾期标外观：当前为红色"逾期"字（可用但非胶囊），新外观里重新定义。
- 二级窗位置：现为屏幕居中，`需求文档-wpf.md` §2.10 / 裁定 R2 定稿为"与待办主窗中心对齐"。
- 批次 04 功能验收项、04b（拖拽排序 / 悬停气泡 / 完成退回动画 / 行悬停过渡 / 批量选中观感）、
  05（设置四项 / 历史页 / CSV / 0 点结算真机验证 / toast）、06（打包与安装）。
- 长期挂起：`preview\TodoWpf.exe` 损坏弹窗（待用户提供原话/截图）。
- **新外观风格选型**——支线的第一步（方向由用户拍板后出原型）。

## 五、流程不变

`AGENTS.md` 全部硬性规定继续适用：一次只改一件事、每笔可单独回退、体验说明书先行、
真机结果为准、`dotnet build` + `dotnet test` 同批通过再提交。

新外观的第一步按既定流程走：**风格选型（1~3 个方向）→ 用户拍板 → 体验说明书 → 实施**。
