## 二、用到的技术

| 技术 | 用途 |
|---|---|
| WPF `WindowChrome` + DWM `SetWindowChertAttribute(33)` | 系统外壳：底边拖拽、Win11 圆角 |
| `LayoutTransform` + 固定设计画布 | 内容随窗口缩放，左上角为锚点 |
| 纯 C# 几何类（`PanelLayout`）+ xUnit | 两窗布局规则 TDD（红/绿两笔） |
| UIAutomation（PowerShell） | 运行时元素定位与点击（⚡ 按钮、勾选框） |
| `EnumWindows` + `GetWindowRect` | 运行时窗口枚举与尺寸测量 |
| `CopyFromScreen` + `GetPixel` | 窗口像素采样（颜色核对） |
| Playwright（原型 HTML） | 原型阶段数值测量与截图 |
| 正则解析原型 CSS vs XAML | 静态数值对照表 |

## 三、遇到的问题与解决

| 问题 | 根因 | 解决 |
|---|---|---|
| 设置页分割线在出现滚动条时消失 | 内容区是 flex 纵列，1px 分割线可收缩被压成 0 | 分割线与分组加 `flex:none` |
| 模板窗出现滚动条 | 高度公式少算 2.5px（41.5+36+8 vs 实际 88）；滚动条被设成常显 | 公式改 `rows*36+88`；滚动条改 Auto |
| 新建模板列表闪烁 | 整表清空重建 | 增量追加：前缀匹配时只加新增项 |
| 主窗底边拖拽与右下角缩放识别冲突 | 两个拖拽热区相邻（底边 8px vs 角标 20px） | 先取消底边拖拽（`ApplyFixed`），高度方案待定（A 单手柄+Shift / B 分离抓手 / C 左右边缘） |
| 贴顶后显隐模板窗两窗错位 | 缩进动画用 `BeginAnimation` 持有窗口 Top，显隐时的布局被动画覆盖 | 显隐前 `ExitTuckBeforeLayout()`：清动画、复位缩进状态、窗口摆回锚点 |
| 令牌测试失败（主窗背景） | 测试断言旧令牌 `Brush.WinBg`，新主窗用 `Brush.Shell` | 测试接受 WinBg 或 Shell；新主窗跳过 GlassEdge 校验 |
| 布局测试失败（窄屏居中） | 主窗 360 后总宽 888 < 1000，不再触发居中 | 窄屏测试改 800 宽 |
| 勾选框样式不对 | 边框 1.5px 灰色 `CbBorder` | 1px、`Brush.Line`（新增令牌） |
| 图片截图模型看不到 | 会话附件被剥离为 `[omitted_binary_payload]` | 改用像素采样（GetPixel）、UIAutomation 量 rect、正则解析 XAML/CSS 对照 |
| 提交时测试红仍进入提交 | 管道（`dotnet test | tail`）吃掉退出码 | 提交前先看完整测试输出 |
| build 锁 DLL | 应用运行中 | 先 `taskkill //F //IM TodoWpf.exe` |
| PowerShell 中文比较失败 | 脚本编码 | 改用尺寸/坐标判断，不比较中文 |
