## 三、怎么操作验证（真机步骤）

1. **三窗与透明**：看缝隙是否直接透出桌面；主窗 ⚡/☑ 点一下 → 左/右卡片收起（只留缝），再点恢复。
2. **拖动**：按住**任一**卡片标题栏拖 → 三张一起动；松手后关掉重开（双击托盘隐藏再显示，或退出重开）→ 位置还在。
3. **吸附+缩进（R1 重点）**：
   - 把组件拖到屏幕最顶（顶边碰上边缘）→ 自动贴齐屏顶；
   - 鼠标移开等约半秒 → **三张卡片保持对齐、整组向上滑出屏幕（约 0.18 秒动画）**，滑完同一刻**白条**出现在屏顶（组件原水平中心）；
   - **鼠标碰到白条** → 白条消失、整组滑回原位；
   - 缩进后再点托盘"显示/隐藏"恢复 → 组件自动弹出停留 3 秒（期间鼠标别放上去，3 秒后自动缩回）；
   - 开"缩进锁定"（标题栏 🔒，按下变亮）→ 贴边永不缩进（已缩进会立即弹出）。
4. **缩放**：拖主窗右下角小角标 → 三张等比缩放；放大到约半屏高/全屏宽会停；缩到最小时元素完整；拖住不放期间组件若弹出则保持弹出。
5. **托盘**：主窗右上角 × → 三窗消失（进托盘）；双击托盘图标 → 恢复；托盘右键 → 「显示/隐藏」「外观预览（工具）」「退出」；**退出**弹确认框（样式=批次 02 确认框规格），确认后程序完全结束。
6. **其他**：标题栏月亮切主题（记忆）；图钉切置顶（组件浮于其他程序最上，记忆）；Alt+F4 = 直接退出（无确认框，退出前数据已落盘）；不进任务栏/Alt+Tab；再开一个 `TodoWpf.exe` → 不会出现第二个，现有组件被唤起。
7. **数据**：首次运行本批版本时，旧版数据自动复制到 `%APPDATA%\桌面待办-WPF\data.json`（旧档原件未动；已在本机验证：15304 字节与旧档一致、跨天补结算 2026-10-12、夜间主题/12 小时制保留）。

## 四、什么算通过

## 六、技术口径（记录）

- Core 纯逻辑可单测：`ClusterLayout`（等比布局/半屏与全宽上限/矮屏取舍/首启右侧偏上）、`TuckStateMachine`（门槛/半秒延时/3 秒会话/动画防重入/锁定与脱附立即弹回）、`ScreenClamp`——37 条新用例锁定（总 140）。
- UI：手写整簇拖动（MouseCapture 下同步三窗，WPF DragMove 无法联动多窗）；上滑动画=窗口 Top 的 SplineDoubleKeyFrame（cubic-bezier(.22,.61,.36,1)，180ms）；白条=独立无边框窗 160×12（MouseEnter 为系统真实命中，被遮挡天然不收事件）；托盘=WinForms NotifyIcon（程序合成蓝底白勾图标，无外部资源）。
- 会话状态：领域 record 不可变，UI 以"替换"变更后经批次 01 仓储防抖落盘（pos/clusterScale/quickVisible/doneVisible/topMost/tuckLock）。
- 单实例：Local Mutex + 命名事件唤醒（第二次启动只唤起现有组件）。
- Alt+F4：任一簇窗 Closing → 落盘 → 退出（需求 §2.2 强退口径）。

### 关于真磨砂的实测结论（如实记录）
- 窗口为**逐像素透明**（需求 §2.1：缝隙与圆角外必须完全透明），实测该形态下 **DWM blur 的可见度有限**：在深色背景上几乎看不出差别；在明亮壁纸上可见明显透出与轻微雾感。Win11 系统背板实验（非分层窗口通道）未见明显模糊，已回滚，保留逐像素透明 + 半透明卡面 + blur behind 调用的组合。
- 结论：当前观感 = 半透明（透出壁纸）+ 若有若无的磨砂；比修复前的"接近不透明黑板"明显改善。**是否需要更强的磨砂/更低的 α，建议并入 E 支线质感选型一起定**（主线不再单独投入）。
