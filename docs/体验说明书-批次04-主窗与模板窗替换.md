# 批次 04 · 主窗与模板窗替换（外壳 + 尺寸 + 静态布局）· 体验说明书

## 你会看到什么

1. **两张卡**：主窗 + 模板窗；快捷窗、已完成窗不再出现。
2. **主窗 360 宽**，默认高度按屏幕工作区一半，夹在 448 到 640 之间。
3. **模板窗 260 宽**，贴主窗右侧、缝隙固定 4；默认收起，点主窗 ⚡ 显隐。
4. **系统外壳**：不透明、Win11 系统圆角；阴影本批不做。
5. **主窗两个手柄**：底边拖高度（最小 448）、右下角等比缩放（0.7 到 1.15）。
6. **缩放联动**：拖主窗右下角，模板窗跟着等比缩放，左缘始终贴主窗右缘 + 4。
7. **高度不联动**：拖主窗底边，只有主窗变高，模板窗高度和位置都不动。
8. **新配色**：日间外壳 `#eef1f6`、待办行白卡 `#fff`；夜间 `#171a1f` / `#252930`。
9. **布局按原型**：主窗标题、时钟、动作行、待办段、已完成段；模板窗标题、动作行、行列表。
10. **数据仍是真实数据**：待办与模板都从现有 Core 读取。

## 怎么验证

1. 启动：只有一张主窗，模板窗收起。
2. 点 ⚡：模板窗出现在右侧，缝隙 4；再点收起。
3. 拖主窗右下角：两窗一起放大/缩小，模板窗左缘始终贴住主窗右缘 + 4。
4. 拖主窗底边：主窗变高，模板窗完全不动。
5. 主窗缩到最小：高度停在 448，内容不裁切。
6. 勾一条待办：进已完成段，显示完成时刻，计数变化。
7. 关掉重开：尺寸、缩放、主题、模板窗开关恢复。
8. 改系统缩放或分辨率：两窗一起压回可见范围，不出屏。

## 什么算通过

- 只有两张卡，⚡ 显隐正常，缝隙恒为 4；
- 缩放联动与高度不联动两条规则不串；
- 两窗都不出屏、不裁切；
- 行高 34、白卡、时间轴、新配色与原型一致；
- 数据与计数正确，重启恢复；
- `dotnet build` 0 错误、`dotnet test` 全绿。
