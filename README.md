# 桌面待办 WPF 版

Windows 桌面悬浮待办小组件（WPF 重写版）：免登录、数据只存本地、不占任务栏、托盘控制显隐。

## 下载安装

到本仓库的 [Releases](https://github.com/Richardo-X/DesktopTodo-WPF/releases) 页面下载最新的
**安装程序**（`桌面待办WPF-安装程序.exe`），双击运行即可；安装时可自行选择安装位置。

## 更新

应用内自带更新：有新版本时标题栏会出现「有新版本！」提示，点击即可更新并自动重启。
更新从本仓库的 Releases 获取。可在设置页关闭「新版本提示」（关闭后不再检查更新）。

## 说明

- 数据保存在 `%APPDATA%\桌面待办-WPF\data.json`，卸载时可选是否一并删除。
- 本仓库仅用于分发安装包与更新包。
