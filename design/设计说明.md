# 设计说明（design 层任务移交 design-taste-frontend）

> 本分支的设计层整体移交给 `design-taste-frontend` 技能（已装于 `.agents/skills/design-taste-frontend`）。
> 本文只划范围、给基准；具体设计结论由新会话用技能产出。

## 一、设计范围（B 类——技能负责）

- **配色体系**：日/夜两套主题令牌（参考 Electron 版 .stage 令牌：文字三阶/悬浮/按钮边框/危险/逾期等）
- **质感**：半透明卡片 + **真 Acrylic 磨砂**（判定 C2，DWM blur behind）
- **字号/间距/圆角阶梯**：从原型提取并系统化（Electron 版口径：圆角 6px 阶梯、间距 4px 栅格）
- **L1 视觉精修全套**（Electron 版已验收的设计决策，直接继承）：
  对比度令牌（日 `#1a1c20/#5d616b/#8b8f99`、夜 `#f2f3f5/#abafb8/#7d818c`）、
  阴影色调化（纯黑→蓝黑 `rgba(10,20,40,…)`）、按压反馈（scale .96）、
  键盘焦点描边、缓出曲线（`cubic-bezier(.22,.61,.36,1)`）、`prefers-reduced-motion` 关怀、
  时钟等宽数字、对话框规格（420px/圆角 10/双层投影）
- **图标系统**：统一线性 SVG 图标集（原型 I.check/plus/chevL/x/clock/trash/undo/bolt/panelCheck…）+ 光学配平原则（同排图标墨迹等高）
- **按钮规格阶梯**：图标按钮 32 / 主按钮 30 / 小按钮 26 / 步进器 28 / 勾选框 20；图标按容器 16/13/11/12px
- **对齐纪律**：操作区按钮与列表行左右端同边
- **操作流畅性**：行 hover 过渡、拖拽排序 FLIP 回弹、完成/退回动效、统一缓动

详细决策与验收口径见 `docs/参考/v1.1.1-L1-体验说明书.md`。

## 三、技能使用要点（给新会话的翻译提示）

design-taste-frontend 的规则是 **CSS/网页语境** 写的；方法论（brief 推断、反 AI 模板味、设计系统构建、audit-first、pre-flight check）完全适用，但产出物必须翻译成 **WPF 资源字典**：

| 技能语境（CSS） | WPF 对应物 |
|---|---|
| CSS 自定义属性（令牌） | `ResourceDictionary` + `SolidColorBrush`/`Color`/`Thickness`/`Double` 资源 |
| Tailwind 类/组件类 | `Style` + `ControlTemplate`（Button/CheckBox/ScrollBar 全套重模板） |
| 线性 SVG 图标 | `Path` + `Geometry`（`Data="M13 2L3 14h7l-1 8 …"`，直接复用原型 path 数据） |
| 缓动曲线 cubic-bezier | `KeySpline`（自定义 `EasingFunctionBase`）或 `CubicEase` 近似 |
| :hover/:active/:focus-visible | Trigger / VisualState（Interaction 触发器） |
| backdrop-filter Acrylic | DWM blur behind（SetWindowCompositionAttribute / Windows 11 DWMWA_SYSTEMBACKDROP_TYPE） |
| prefers-reduced-motion | 系统设置读取（SystemParametersInfo SPI_GETCLIENTAREAANIMATIONS）→ 关闭动画开关 |

**禁止**：手写无令牌的裸颜色/尺寸；跳过技能直接写 XAML 样式；把 Electron 版 XAML 不存在的实现细节当需求。
